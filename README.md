# Top200 多因子回测框架

框架在交易日 `T` 使用 `T-1` 收盘后得到的因子；首次等权买入 Top200，之后每天最多替换 30%（60 只）。交易使用 TWAP，双边费率 14bp，并处理 ST、停牌、涨跌停、100/200 股交易单位和后复权因子引起的持股数量变化。

## 运行

```powershell
pip install -r requirements.text
python main.py --market A500 --start 2020-01-01 --end 2024-12-31
```

也可以启动本地可视化控制台：

```powershell
python web_app.py
```

然后访问 `http://127.0.0.1:8000`，在网页中选择票池、日期与初始资金。页面会显示当前回测日期和整体进度，完成后可直接打开完整静态报告。服务仅监听本机地址；按 `Ctrl+C` 停止。

票池可选 `A500`、`ZZ1000`、`ALL_A500`、`ALL_ZZ1000`；`ALL_*` 表示全市场选股，后缀决定基准。全部参数集中在 `config.py`。数据为行索引日期、列为六位证券代码的宽表。

输出在 `output/`：`index.html` 静态报告，以及账户、每日持仓、委托、已平仓交易和指标文件。可直接用浏览器打开 HTML。

## 口径

- TWAP 和收盘价视为后复权价，实际价格 = 后复权价 / 当日累计复权因子。
- 涨跌停以实际 TWAP 相对昨日实际收盘计算；300、688 为 20%，其余为 10%。涨跌停和停牌均不买不卖。
- 无法卖出的持仓继续持有，因此极端情况下持仓可能暂时偏离目标名单；不会为了凑数突破 200 只。
- “等权”用于首次建仓和新纳入股票的目标资金；受交易单位、费用、停牌及涨跌停约束会有现金余量。
- 平仓盈亏记录采用持仓平均成本；复权变动时数量乘以新旧复权因子之比、单位成本反向调整。

## 当前数据状态

仓库中的 `twap.parquet` 与 `factordata.parquet` 缺少合法 Parquet footer，需从原始来源重新复制/导出后才能执行真实数据回测。加载器会给出明确错误，其余数据文件可正常读取。
