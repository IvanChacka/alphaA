# 2024样本外模型与策略对比分析（更新版）

更新日期：2026-07-16
统一口径：`ALL_ZZ1000`表示全市场选股、ZZ1000作为基准；初始资金1亿元；测试区间为2024年；超额指标全部由`策略净值 / 基准净值`计算。

## 最终结论

当前最优策略选择：**固定PCA90风格轮动 + 双期限XGBoost择时 + 惰性换手 + 二次规划动态仓位，不使用残差分数**。

- 运行目录：`run_20260716_165342_style_rotation`
- 年化收益：**15.16%**
- 2024累计收益：**14.46%**
- 夏普：**0.677**
- 最大回撤：**-17.06%**
- 相对ZZ1000年化超额：**13.08%**
- 超额夏普：**0.751**
- 最终股票RankIC：**0.0396**
- ICIR：**0.3967**
- 正IC交易日比例：**67.36%**
- 换手：**15.82**
- 交易费：**209.84万元**
- 平均目标仓位：**59.05%**，最低目标仓位30%

这里的“最优”采用稳健性优先标准，不表示它在每个单项指标上都是最高。残差权重1.0的版本年化收益和夏普更高，残差权重0.3的版本费用更低；当前版本胜在模型更简单、最终IC/ICIR更稳定、最大回撤最低、对残差alpha不敏感，同时保留了较高的超额收益。

## 为什么选择当前版本

### 1. 相比未优化StyleRotation，风险和成本改善巨大

当前版本相对`run_20260716_134902_style_rotation`：

- 年化收益只减少1.67个百分点：16.83%降至15.16%。
- 夏普从0.585提高到0.677。
- 最大回撤从-34.12%改善至-17.06，回撤幅度约减半。
- 换手从64.96降至15.82，下降75.7%。
- 交易费从847.49万元降至209.84万元，下降75.2%。
- 相对ZZ1000仍保留13.08%的年化超额。

这说明惰性换手和二次规划动态仓位没有简单地牺牲全部收益换取低风险，而是显著改善了收益质量。

### 2. 相比PCA95版本，PCA90更精简

当前版本相对无残差PCA95版本：

- PCA成分从16个减少到13个。
- 累计解释率仍达到90.33%。
- 年化收益只减少0.33个百分点。
- 最大回撤进一步改善0.15个百分点。
- 换手下降20.4%，费用下降20.6%。
- RankIC只从0.0400轻微变化到0.0396。
- ICIR从0.389提高到0.397。

因此后3个低方差成分带来的增量收益有限，却增加了交易和模型复杂度。PCA90是更合理的精简点。

### 3. 不使用残差分数更稳健

残差权重1.0的版本拥有最高年化和夏普，但最终RankIC只有0.0328、ICIR只有0.259；残差权重0.3的结果又明显依赖Ridge alpha。当前版本关闭残差后：

- RankIC回升至0.0396。
- ICIR提高至0.3967。
- 不再依赖残差alpha选择。
- 组合最大回撤低于两个残差版本。
- 避免用单一年份表现反向选择残差权重。

残差模型仍可作为收益增强候选保留，但在多年度样本外验证前不进入当前主策略。

### 4. PCA没有压坏原始因子

使用2024年相同日期和相同`t1→t2`标签对比；原始因子按各自非缺失观测计算，PCA风格按模型实际预处理后的截面计算：

| 对象 | 数量 | 平均RankIC | 中位数RankIC | 最优RankIC | 最差RankIC |
|---|---:|---:|---:|---:|---:|
| 原始因子 | 30 | 0.0163 | 0.0154 | 0.0456 | -0.0124 |
| 当前PCA风格 | 13 | **0.0211** | **0.0193** | **0.0489** | **-0.0018** |

13个PCA风格中12个全年RankIC为正，最优的`style_4`为0.0489。原始因子本身的平均预测能力较弱，PCA压缩后的平均值和尾部反而更好。因此单风格RankIC较小并不是压缩程序错误，而是原始因子信号上限和市场状态变化共同造成的。

## 收益路径

当前版本季度收益：

| 季度 | 当前策略 | 解释 |
|---|---:|---|
| 2024Q1 | -8.14% | 动态降仓限制年初下跌损失 |
| 2024Q2 | -6.81% | 信号最弱季度，RankIC约0.0218 |
| 2024Q3 | +16.20% | 捕捉市场反弹，是全年主要收益来源 |
| 2024Q4 | +15.07% | 风格RankIC和多空分层改善，延续收益 |
| 全年累计 | +14.46% | 期末净值1.1446 |

Q1、Q2仍连续亏损，说明二次规划只减少风险而不能消除市场暴露；全年结果主要依赖下半年恢复。当前策略不能据此视为低风险绝对收益策略。

## 当前仍需保留的风险提示

1. 目前只有2024一个完整样本外年度，策略选择仍可能含有年度内参数试验偏差。
2. 当前版本是“稳健性优先”的主策略，残差0.3和残差1.0仍是收益增强挑战者，不能用一年结果永久淘汰。
3. 平均目标仓位只有59.05%，与满仓策略的收益不能脱离风险暴露直接比较。
4. 二次规划调仓169天，虽然总换手和费用下降，但产生22,982笔较小订单；实盘容量和冲击成本仍需压力测试。
5. `ALL_ZZ1000`是全市场选股、ZZ1000基准，不是仅在中证1000成分股内选股。
6. 行业中性化优化器本次未启用，当前收益可能包含行业偏离贡献。

## 后续验证顺序

1. 固定当前参数，不再根据2024结果调整，滚动验证2020—2023或取得2025独立样本。
2. 对当前策略进行费用28bp、冲击成本和成交容量压力测试。
3. 单独比较`residual_weight=0、0.3、1.0`的多年度表现，不再只比较2024。
4. 分别在`ZZ1000`成分池、`A500`成分池和全市场验证信号迁移性。
5. 最后再测试行业中性化，避免同时改变模型、仓位和行业约束。
