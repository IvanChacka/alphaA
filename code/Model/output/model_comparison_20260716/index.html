为什么选择当前版本

风险明显下降

相对未优化StyleRotation，最大回撤从34.12%降到17.06%，年化只减少1.67个百分点。

交易成本可控

换手15.82、费用209.84万元，较未优化版本分别下降75.7%和75.2%。

信号更稳定

关闭残差后RankIC 0.0396、ICIR 0.3967，显著高于残差权重1.0版本的0.0328和0.259。

结构更精简

PCA90用13个风格保留90.33%信息；相对PCA95减少3个成分，IC基本不变，换手和费用再降约20%。
